# Известные ограничения

- Несовместим с оригинальным Podkop: перед установкой удалите `podkop` и `luci-app-podkop`
- `dns_type=dot` не поддерживается; доступны только `udp` и `doh`
- Файлового кэша FakeIP нет. После перезапуска ядра у клиентов до ~60 секунд могут встречаться устаревшие fake-IP
- VPN-секции не поддерживают доменные списки
- Формат `.srs` не поддерживается; используйте plain или `.json`
- Hysteria2 требует Xray >= 26.1.13
- Маршрутизация работает только по IPv4
- `resolve_real_ip_for_routing` не поддерживается
