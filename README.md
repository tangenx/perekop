# Perekop

Perekop — маршрутизация трафика OpenWrt на базе Xray-core. Направляйте выбранные ресурсы через туннель, а остальные — напрямую.

Perekop is based on the Podkop open-source project by itdog.info (https://github.com/itdoginfo/podkop). Podkop is a trademark of itdog.info; Perekop is an independent fork, not affiliated with or endorsed by itdog.info.

> [!WARNING]
> Проект находится в стадии бета-версии. Возможны ошибки, нестабильная работа и существенные изменения функциональности.

## Установка

Требуется OpenWrt 24.10 или новее и не менее 25 МБ свободного места. Установить или обновить Perekop можно командой:

```sh
sh <(wget -O - https://raw.githubusercontent.com/tangenx/perekop/main/install.sh)
```

Для Hysteria2 нужен Xray версии не ниже 26.1.13. В OpenWrt 24.10 в пакетах доступна версия 25.1.30; установите свежий бинарник из релизов XTLS:

```sh
sh <(wget -O - https://raw.githubusercontent.com/tangenx/perekop/main/install.sh)
```

Затем ответьте `y` на вопрос об установке бинарника Xray либо запустите скрипт с `--xray-latest`.

```sh
sh -c "$(wget -O - https://raw.githubusercontent.com/tangenx/perekop/main/install.sh)" -- --xray-latest
```

## Known limitations

- Несовместим с оригинальным Podkop (это его форк): перед установкой удалите `podkop` и `luci-app-podkop`.
- `dns_type=dot` не поддерживается; доступны только `udp` и `doh`.
- Файлового кэша FakeIP нет. После перезапуска ядра у клиентов до примерно 60 секунд могут встречаться устаревшие fake-IP.
- Списки обновляются без перезапуска ядра, если содержимое фактически не изменилось.
- VPN-секции не поддерживают доменные списки.
- Формат `.srs` не поддерживается; используйте plain или `.json`.
- Hysteria2 требует Xray >= 26.1.13 (сток OpenWrt 24.10 — 25.1.30); установите свежий бинарник через `install.sh --xray-latest`.
- В mixed-прокси SOCKS работает на выбранном порту, HTTP — на порту +1.
- `resolve_real_ip_for_routing` (DNS-resolve sing-box при маршрутизации) не поддерживается.
- Маршрутизация работает только по IPv4: fake-IP, tproxy и списки подсетей — IPv4. IPv6-трафик клиентов обходит туннель и раскрывает реальный адрес клиента, поэтому он отбрасывается настройкой «Block IPv6» (включена по умолчанию). Отключайте её только если IPv6 клиентам не нужен.

## Важно знать

- При обновлении очистите кэш LuCI и проверьте конфигурацию: она может измениться между версиями.
- При запуске Perekop изменяется конфигурация Dnsmasq и Xray.
- Если установлен Getdomains, удалите его перед установкой Perekop.

## Поддержка

О проблемах сообщайте в [GitHub Issues](https://github.com/tangenx/perekop/issues), приложив версию OpenWrt, модель устройства и диагностическую информацию. Не публикуйте секреты и ключи из конфигурации.
